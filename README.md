# P&L Analysis – Markets & Sub Zones

## 📊 Project Overview

An Excel-based P&L analysis project focused on evaluating financial performance across different markets and sub-zones.

## 🔍 Analysis Performed

→ Analyzed Net Sales and COGS
→ Calculated Gross Margin and Gross Margin %
→ Compared market-level profitability
→ Analyzed quarterly GM% by Sub Zone
→ Compared performance across financial years
→ Used filters to analyze regions, sub-zones, and financial years
